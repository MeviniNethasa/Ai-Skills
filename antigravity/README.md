## ➕ Add an Antigravity Skill

```bash
mkdir -p antigravity/skills/<skill-name>
cp templates/SKILL_TEMPLATE.md antigravity/skills/<skill-name>/SKILL.md
```

Then add a row to the table above and to the catalog in the root [`README.md`](../README.md#-skill-catalog).

> [!TIP]
> Porting a Claude skill? Copy it here, adjust any assistant-specific wording, and link both versions to each other under **Related**.
